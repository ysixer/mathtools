이차함수와 이차방정식

슬라이더로 a, b, c를 바꾸거나 꼭짓점을 직접 끌어 보세요.

이차방정식 ax² + bx + c = 0의 실근은 포물선이 x축과 만나는 점의 x좌표입니다. 그래서 판별식 D = b² − 4ac의 부호가 교점의 개수를 알려 줘요.

표준형 꼭짓점 판별식 D = b² − 4ac 실근 x축과의 교점
  • D > 0 · 서로 다른 두 실근 · 두 점에서 만남
  • D = 0 · 중근 · 한 점에서 접함
  • D < 0 · 서로 다른 두 허근 · 만나지 않음

초록 꼭짓점을 끌면 a는 그대로 두고 그래프를 평행이동해요. 꼭짓점이 x축을 지나는 순간 교점의 개수가 바뀝니다.
