삼각형의 외각

꼭짓점 A, B, C를 끌어 보세요. 외각과 두 내각의 합이 늘 같이 움직입니다.

∠ACD = ∠A + ∠B

삼각형의 한 외각의 크기는 그와 이웃하지 않는 두 내각의 크기의 합과 같습니다.

∠A ∠B ∠A + ∠B 외각 ∠ACD ∠C (내각) 세 내각의 합
∠A + ∠B
외각 ∠ACD
0°180°
왜 성립할까?
  1. 점 C를 지나고 AB에 평행한 직선 CE를 긋습니다.
  2. AB ∥ CE이므로 ∠ACE = ∠A (엇각), ∠ECD = ∠B (동위각).
  3. 따라서 ∠ACD = ∠ACE + ∠ECD = ∠A + ∠B. 이 식은 세 내각의 합이 180°라는 사실과도 같은 이야기입니다.
