외각의 이등분선 정리

꼭짓점 A, B, C를 끌어 보세요. 빈 곳을 끌면 화면이 이동합니다.

AB : AC = DB : DC

∠A의 외각을 이등분한 직선이 변 BC의 연장선과 만나는 점을 D라고 하면, D에서 두 꼭짓점까지의 거리의 비는 외각을 이루는 두 변의 길이의 비와 같습니다.

왜 성립할까? (보조선을 이용한 증명)
  1. 점 C를 지나고 AD에 평행한 직선이 직선 AB와 만나는 점을 F라고 합니다.
  2. FC ∥ AD이므로 동위각과 엇각이 각각 외각의 절반과 같아져 ∠AFC = ∠ACF. 따라서 AF = AC입니다.
  3. 점 B에서 뻗은 두 직선을 평행선 FC, AD가 자르므로 AB : AF = DB : DC.
  4. AF = AC를 대입하면 AB : AC = DB : DC.

AB = AC이면 외각의 이등분선이 BC와 평행해져 점 D가 생기지 않습니다. 두 변을 비슷하게 맞춰 가며 D가 멀리 달아나는 모습을 확인해 보세요.
